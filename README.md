
# My Cafe Website

My Cafe is a simple and responsive cafe website where users can explore our menu, view food prices, and contact the cafe. This project is created using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Home, Menu, About and Contact sections
- Responsive website design
- Light and Dark Mode
- Contact form with personalized message
- Menu table row highlighting
- Order total calculator
